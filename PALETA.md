# Paleta de colores — Bañópolis

Resumen de las variables CSS y colores usados en la UI.

- **--color-bg**: #EAF1F0 — Fondo general de la app.
- **--color-surface**: #FFFFFF — Superficies / tarjetas / modales.
- **--color-ink**: #16292B — Texto principal.
- **--color-ink-soft**: #4B6467 — Texto secundario / descripciones.
- **--color-primary**: #1B6B72 — Color principal (botones, iconos, pins gratuitos).
- **--color-primary-dark**: #114A4F — Variante oscura del primario (texto y `theme` del manifest).
- **--color-primary-soft**: #DCEBEA — Fondo/estado suave del primario.
- **--color-accent**: #E8A33D — Color de acento (pins de pago, highlights).
- **--color-accent-dark**: #B97C22 — Variante oscura del acento.
- **--color-accent-soft**: #FBEBD2 — Fondo/estado suave del acento.
- **--color-rose**: #C24A56 — Color de alerta/advertencia (reportes).
- **--color-rose-soft**: #FBE4E7 — Fondo suave para alertas.
- **--color-line**: #D7E3E2 — Líneas y separadores.

Nota: el `manifest.json` usa `background_color` y `theme_color` con el valor `#114A4F` (coincide con `--color-primary-dark`).

Usos destacados
- Fondo general: `--color-bg`.
- Superficies, modales y tarjetas: `--color-surface`.
- Texto principal y secundario: `--color-ink` / `--color-ink-soft`.
- Acciones y elementos destacados: `--color-primary` y `--color-accent`.
- Badges/avisos: `--color-rose` y `--color-rose-soft`.
